Frelon Tracker

Suivi en temps réel avec détection de couleur

ℹ️ Cette application est une PWA (Progressive Web App). Vous pouvez l'installer sur votre écran d'accueil pour l'utiliser comme une app native.
RECOMMANDÉ

v3.0

Calibrage spatial + blob detection. Corrige la distorsion caméra.

 STABLE

v2.0

Détection blob sans calibrage.

Fonctionnalités

  • Flux vidéo en niveaux de gris
  • Détection de couleur orange/jaune en temps réel
  • Pastille magenta qui suit l'objet
  • Compteur FPS live
  • Mode Debug pour le calibrage
  • Fonctionne offline une fois installée

📱 Comment installer sur smartphone

  1. Android (Chrome) : Appuyez sur ⋮ → "Ajouter à l'écran d'accueil"
  2. iOS (Safari) : Appuyez sur ↗️ → "Ajouter à l'écran d'accueil"
  3. Lancez l'app depuis votre écran d'accueil
